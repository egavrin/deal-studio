Сценарии демки

Переключатели ниже меняют один и тот же чат-экран, а не отдельные страницы.

Что переносим в Compose

  • Правый user bubble: pale blue, компактный радиус, без тяжелых теней.
  • Левый assistant bubble с маленьким avatar/sparkle.
  • Виджеты как белые bordered cards, не nested cards.
  • TimerCard: крупный countdown, progress ring, Pause и Cancel.
  • WeatherCard: температура, метрики, forecast row, source chip.
  • GenericAnswerCard: plain answer; источник local model только для internal/debug.

Architecture note

AssistantResponse.widget остается data-only. Android UI выбирает renderer по widget.type. Qwen отвечает текстом, не генерирует JSON и не подстраховывает RuBERT.
